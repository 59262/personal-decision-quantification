# 决策状态快照填写模板

> **填写边界：** 只记录预测锁定时已知的信息。不要填写实际选择、实际结果、事后反思，或对“真实动机”的判断。
>
> 无关字段填 `not_applicable`；暂时无法判断填 `unknown`。同一字段在不同预测中须保持相同含义。

## A. 记录元数据

- 快照 ID：`S-`
- 预测 ID：`P-`
- 捕获时间：`YYYY-MM-DD HH:MM +08:00`
- 预测窗口：`例如：未来 3 小时 / 今晚睡前`
- 记录者（可选）：
- 数据来源：`pre_lock_user_report`

## B. 核心快照（每条预测必填）

- 当前时间：
- 地点：
- 是否已到行动地点：`yes / no / uncertain`
- 距下一固定安排：`__ 分钟`
- 精力（0–5）：`__`
- 压力 / 认知负荷（0–5）：`__`
- 当天中心主轴：
- 外部限制：`none / time / transport / weather / others / equipment / money / body`
- 身体不适（如适用）：

评分锚点：

| 分数 | 精力含义 |
|---:|---|
| 0 | 无法正常行动 |
| 1 | 非常低 |
| 2 | 偏低 |
| 3 | 一般 |
| 4 | 较好 |
| 5 | 非常充沛 |

> 压力 / 认知负荷同样固定使用 0–5；不要让同一分数在不同日期含义漂移。
